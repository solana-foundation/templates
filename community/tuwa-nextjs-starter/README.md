# TUWA Starter (Next.js)

[![License: MIT-0](https://img.shields.io/badge/license-MIT--0-blue.svg)](./LICENSE)

A Next.js app for Solana with Wallet Standard wallets, SIWX sign-in (CAIP-122) and tracked program calls, built on the TUWA SDK (`@tuwaio/sdk` with `@tuwaio/solana-sdk`). The build contains no EVM code of TUWA. It is maintained as the `nextjs-solana` template of [Cosmos Playground](https://github.com/TuwaIO/cosmos-playground); the [React transaction tracking guide](https://docs.tuwa.io/guides/react-transaction-tracking) explains the tracking code step by step and the [Full-Stack React guide](https://docs.tuwa.io/guides/full-stack-react) the sign-in (Solana tab).

---

## 🚀 Quick Start

```bash
npx create-solana-dapp@latest my-app --template tuwa-nextjs-starter
cd my-app
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with a Solana wallet extension (for example Phantom or Solflare) set to devnet. Node.js 20.19+, 22.13+ or 24+ is required (the `engines` range of ESLint 10). For local development every variable in `.env` is optional; `build` and `start` need `SIWX_DEMO_SIGNING_SECRET`. The scripts below are shown with pnpm; they run the same way with npm or yarn.

---

## 🎯 What It Shows

- **Wallet connection** with the Nova Connect modals on Satellite Connect, for every wallet that supports Wallet Standard. Satellite Connect reconnects the last wallet after a page reload.
- **SIWX sign-in:** Nova Connect asks every connected wallet to sign a CAIP-122 message with a nonce from the server; the server verifies it and keeps the session in an `HttpOnly` cookie. A wallet that refuses to sign is disconnected.
- **Tracked transactions** with Pulsar and the Nova Transactions modals and toasts: a counter program on devnet, with the client generated by Codama from the Anchor IDL. Create a counter account, increment, decrement or close it. A transaction shows as confirmed in about a second, then as finalized.
- **Transaction history** saved to `localStorage`, with tracking that resumes after a reload.

## 🔧 Environment Variables

| Variable                   | Description                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| `SIWX_DEMO_SIGNING_SECRET` | Signs the session cookies, at least 32 characters (`openssl rand -base64 32`). Required in production     |
| `NEXT_PUBLIC_APP_URL`      | Origin of the app: the only domain the SIWX server accepts. Default: `http://localhost:3000`              |
| `NEXT_PUBLIC_ALCHEMY_KEY`  | Alchemy key for the Solana Mainnet RPC URL. Default: `https://api.mainnet-beta.solana.com` (rate-limited) |

The devnet program uses the public `https://api.devnet.solana.com`.

## 🛡️ SIWX Sessions

The template uses the **stateless demo profile** of `@tuwaio/siwx-server`, so it runs without a database: the session is a signed token in an `HttpOnly` cookie and expires after 30 minutes. Its limits:

- a session cannot be revoked before it expires;
- used nonces are remembered in the memory of each server instance, so with several instances a signed message can be replayed on another one within 5 minutes.

For production, switch `src/app/api/siwx/[...siwx]/route.ts` to `createSiwxApiHandler` with a shared session and nonce store (Redis or a database), as described on the [`@tuwaio/siwx-server`](https://siwx.docs.tuwa.io/packages/siwx-server) page. Server code reads the session from the cookie with `getSiwxServerSession`; never trust a session object sent by the browser.

## 📁 Project Structure

```
src/
├── app/           # Next.js App Router: layout, page and the /api/siwx route
├── components/    # Header, home page, the transaction block and its buttons
├── configs/       # Solana RPC URLs
├── constants.ts   # Address of the counter program
├── hooks/         # Pulsar store, store of the counter accounts
├── lib/           # Signing secret of the SIWX sessions
├── programs/      # Codama client of the program (generated/ is rebuilt by `pnpm generate:solana`)
├── providers/     # Satellite Connect, Nova Connect (with SIWX) and Nova Transactions providers
├── styles/        # Tailwind CSS v4 and the Nova stylesheets
├── targets/       # Anchor IDL of the program
└── transactions/  # The transaction actions and their types
```
